# Адреса пересылателя отчётов «Рядом».
#
# Этот файл — запасной путь на случай, когда встроенные в exe адреса
# заблокированы, а не переехали. Приложение читает его ТОЛЬКО после того,
# как все встроенные адреса отказали (см. internal/report/send.go), так
# что на обычный отчёт он не стоит ни одного запроса.
#
# Читается по сырой ссылке с ветки main репозитория Nearby-Lan-Chat, а не
# из ассета релиза: ассет принадлежит одной версии, и человек на старой
# сборке получил бы старый список — именно тот человек, которому рабочий
# список нужнее всего.
#
# Формат: по адресу в строке, со схемой. Пустые строки и строки с # —
# комментарии. Приложение дописывает /report само.
